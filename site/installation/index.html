Installation

news-fetch requires Python 3.10+.

From PyPI

pip install news-fetch

From source

git clone https://github.com/santhoshse7en/news-fetch.git
cd news-fetch
pip install .

Dependencies

news-fetch is intentionally lightweight (~50MB): newspaper4k, beautifulsoup4, requests, lxml-html-clean, and Unidecode. No optional extras, no Scrapy, no boto3, no Selenium.
